В папке www/index.html лежит само приложение PastMetki (один HTML-файл).
Его можно:
 1) загрузить в онлайн-конвертер HTML -> APK, или
 2) собрать через GitHub (вкладка Actions, файл .github/workflows/build.yml), или
 3) открыть проект в Android Studio (npm install, npx cap add android, npx cap open android).

Обновление поверх старой версии:
 - debug.keystore в корне проекта - фиксированный ключ подписи. Все APK, собранные через
   GitHub Actions с этим файлом, подписаны одним ключом и устанавливаются поверх друг друга.
 - versionCode растёт с каждой сборкой автоматически.
 - Если на телефоне уже стоит PastMetki, собранная раньше с ДРУГИМ ключом, один раз удалите её,
   потом ставьте новую.

Версия 1.0.7:

 - сайт: тот же index.html работает на ПК (боковое меню, чаты в две колонки) и на телефоне, данные и аккаунты общие.
   Публикация сайта: см. раздел «Сайт» ниже. firestore.rules нужно опубликовать заново (появились приглашения).
Версия 1.0.6:

ВАЖНО: firestore.rules нужно заново опубликовать в консоли Firebase (там добавлены группы).

Виджеты (долгое нажатие на рабочем столе -> Виджеты -> PastMetka): чаты, заметки 2x2/3x3/4x4 (с галочками),
дедлайны, быстрые действия 4x1 и 2x1, плюс 1x1, процент за сегодня 2x1, сегодня 1x2.
Фон виджета: значок ⚙ на виджете или долгое нажатие -> Настроить (Android 12+). Отметки с виджета
применяются к данным при следующем открытии приложения.
Нативный код лежит в native/. Виджеты берут данные из кэша, который приложение обновляет при работе.

Сборка (GitHub Actions): native/prep.sh (иконка + версия + разрешения, любая ошибка останавливает сборку),
затем native/install.py + gradle, затем native/verify.sh (проверка иконки, версии, виджетов в APK).
Если сборка с виджетами не удалась, workflow соберёт APK без виджетов и закончится КРАСНЫМ статусом.
Иконка: assets/icon-only.png, icon-foreground.png, icon-background.png (генерируется @capacitor/assets).
firestore.rules нужно вставить в консоль Firebase (Firestore -> Rules -> Publish).


САЙТ (ПК + телефон, те же аккаунты и данные)
Сайт - это та же папка www/ (index.html, manifest.webmanifest, sw.js, иконки). Хостинг Firebase бесплатный (тариф Spark).
Один раз:  npm i -g firebase-tools   ->   firebase login
Дальше из папки проекта:  firebase deploy
Эта команда публикует и сайт, и firestore.rules. Адрес сайта: https://pastmetki.web.app (и pastmetki.firebaseapp.com),
эти домены уже разрешены для входа. Другой домен (свой или github.io) нужно добавить в Firebase ->
Authentication -> Settings -> Authorized domains. Вариант без консоли: GitHub Pages (workflow "Deploy site", запуск вручную).
На телефоне сайт можно установить как приложение (меню браузера -> «Добавить на главный экран»).
